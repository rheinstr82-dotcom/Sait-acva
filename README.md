# OASYS Water Park Systems — 3D Banner

Интерактивный 3D-баннер с фото и текстом.

## Как опубликовать на GitHub Pages

1. Создайте новый репозиторий на GitHub (например `oasys-banner`)
2. Загрузите **всю папку** `oasys-site` в корень репозитория:
   - `index.html`
   - `images/` (со всеми 4 фото)
   - `README.md`
3. Settings → Pages → Source: **Deploy from a branch**
4. Branch: `main` → Folder: `/ (root)` → Save
5. Через 1–2 минуты сайт будет доступен по адресу:

   `https://ВАШ_НИК.github.io/oasys-banner/`
